# Восстановление SMTP для TATTOO PRICE через Beget

22.10.2026. Скрипт находится в подготовительной ветке, **на VPS ещё не выполнялся**.

Использует созданный в панели Beget почтовый ящик `noreply@yabylzdes.ru`, `smtp.beget.com:465` (TLS). Восстанавливает доставку писем из *общей* инстанции Supabase Auth (`api.smoke-tattoo.ru`), используемой TATTOO PRICE и закрытым тестовым ЗАГСом.

## Контрольная последовательность

На ПК, в PowerShell: `ssh root@45.80.68.40`. Дальше **только внутри SSH**, после появления `root@...#`:

```bash
curl -fsSLo /root/backups/tp-smtp-restore.py https://raw.githubusercontent.com/dimontattoo495-afk/tattoo-price/COMMIT_SHA/ops/beget-restore-auth-smtp.py
python3 /root/backups/tp-smtp-restore.py
```

Заменить `COMMIT_SHA` на неизменяемый commit SHA от проверенной версии скрипта. Не запускать неизвестный или не закреплённый `main`.

Программа:
1. Проверит принадлежность запущенного контейнера `supabase-auth` Docker Compose и сравнит действующее SMTP с файлом Compose `.env`.
2. Попросит пароль от ящика локально через невидимый ввод (НЕ через чат и не GitHub).
3. Проверит `smtp.beget.com:465`: шифрование, SMTP LOGIN и приём **одного пробного письма самому себе**.
4. Подготовит изменения только шести SMTP-переменных и проверит, что **состав/конфигурация остальных Compose-сервисов полностью совпадают**.
5. До записи потребует ввод `APPLY`. При отмене исходный файл сохранится.
6. Сделает резервную копию исходного `.env` в `/root/backups/` (права 0600).
7. Пересоздаст только Compose-службу `auth` с параметром `--no-deps`, затем проверит реальную среду запущенного контейнера.
8. При ошибке попытается вернуть предыдущий файл и контейнер.

Ограничения:
- Секреты, токены и пароли **не выводятся**. Результат пробного SMTP LOGIN и принятия письма ещё не доказывает его реальной доставки внешнему клиенту.
- **Не отключает** обязательное подтверждение email, не изменяет пользователей, таблицы `tp_*`, платежи и другие Docker-сервисы.
- Если `STOP`, не продолжать вручную или изменять Docker Compose без выяснения причины.
- После `PASS` проверить реальную регистрацию, получение письма и ссылку подтверждения на TATTOO PRICE. Проверить отдельно уведомления приложений, которые могли иметь свою доставку почты.
- Настройки DNS домена, SPF/DKIM/DMARC и MX-получателя необходимо проверить отдельно, если письмо не приходит или попадает в спам.
