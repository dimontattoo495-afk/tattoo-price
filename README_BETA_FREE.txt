TATTOO PRICE — BETA FREE MODE V1

Что делает режим:
- новые объявления публикуются сразу;
- банковская карта не нужна;
- Т-Банк НЕ вызывается для новых бесплатных публикаций;
- срок бесплатной публикации: 15 дней;
- бесплатный режим только «Стандарт»;
- администратор по-прежнему может скрыть/отклонить/удалить публикацию;
- реальные платные объявления и уже существующие платежи не меняются;
- автоматических списаний нет.

ВАЖНАЯ ЗАЩИТА
SQL-триггер является главным предохранителем:
даже если у посетителя закэширован старый JavaScript, новое объявление
во время бета-режима получает status=published + payment_status=paid
и is_beta_free=true. Поэтому существующая платежная функция увидит его
как уже оплаченное и не создаст банковский платеж.

Установка:
1) Загрузить эти файлы в GitHub repo tattoo-price поверх текущих.
2) Подождать ~2 минуты: ваш Beget auto-deploy сам обновит price.smoke-tattoo.ru.
3) Подключиться по SSH к серверу.
4) Выполнить ОДНУ команду:

docker exec -i supabase-db psql -U postgres -d postgres < /root/supabase-project/volumes/site/09_BETA_FREE_MODE.sql

5) Проверить:
https://price.smoke-tattoo.ru/publish.html

На форме должно быть:
«БЕТА-ЗАПУСК», «0 ₽», кнопка «ОПУБЛИКОВАТЬ БЕСПЛАТНО».

Как выключить бесплатный режим позже:
docker exec supabase-db psql -U postgres -d postgres -c "update public.tp_site_settings set beta_free_enabled=false, updated_at=now() where id=1;"

После выключения новые объявления снова пойдут по обычной платной схеме.
Старые бесплатные объявления останутся активны до своей даты expires_at.

Примечание:
это режим мгновенной публикации с ПОСТМОДЕРАЦИЕЙ. Рекомендуется регулярно
проверять новые работы в админке, потому что бесплатная мгновенная публикация
снижает барьер для спама.
